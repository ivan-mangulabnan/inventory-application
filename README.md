<p align="center">
  <em>A lightweight inventory management app built with modern Node.js tools.</em>

---

### 🧩 Tech Stack

| Purpose | Tools Used |
|----------|-------------|
| **Backend** | [Node.js](https://nodejs.org/) |
| **Routing** | [Express](https://expressjs.com/) |
| **Database** | [PostgreSQL](https://www.postgresql.org/) |
| **Templating** | [EJS](https://ejs.co/) |
| **Validation / Sanitization** | [Express-Validator](https://express-validator.github.io/docs/) |
| **HTTP Methods Support** | [Method-Override](https://www.npmjs.com/package/method-override) |
| **Icons** | [Heroicons](https://heroicons.com/) |
| **Styling** | Vanilla CSS (Responsive) |

---

### 🗂️ Overview

This project demonstrates how to build a full-featured inventory system using:
- RESTful routing with Express  
- Modular EJS components for UI  
- Secure input validation and sanitization  
- PostgreSQL for persistent data storage  
- Clean, responsive layout using vanilla CSS
